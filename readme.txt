This project is a demo for prime+probe based side channel attack on Apple M1's System-level cache. 

To install the side channel library:
cd pylib
./com.sh

test_Cprime.py and test_Gprime.py show examples for the 2 side channels described in Section 4, plot_case1.py and plot_case2.py shows the 2 methods for analysising side channel traces described in Section 5.1.
